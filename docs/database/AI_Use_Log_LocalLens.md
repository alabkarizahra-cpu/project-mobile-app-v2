# AI Use Log -- LocalLens Project

## Tool Used

-   **Tool:** ChatGPT
-   **Purpose:** Assistance with reviewing and documenting the database
    design.

## Section: Database Design and ER Diagram

### Purpose of Use

ChatGPT was used to help review the ER Diagram and check its consistency
with the updated Data Dictionary.

### Tasks Assisted

-   Reviewed the new attributes added to the Experience, Itinerary, and
    Trip entities.
-   Discussed Primary Keys (PK) and Foreign Keys (FK).
-   Checked the entity relationships and cardinalities in the ER
    Diagram.
-   Helped clarify how the ER Diagram should match the Data Dictionary.
-   Provided guidance on documenting and uploading the updated diagram
    to GitHub.

### Personal Review and Modifications

I reviewed the suggestions and compared the ER Diagram with the Data
Dictionary. I made the required updates to the diagram, checked the
fields and relationships, and uploaded the updated diagram to the
repository. I also created the related GitHub Issue and Pull Request and
completed the merge after reviewing the changes.

## Responsibility

The final decisions, review, modifications, and submission of my work
were completed by me. ChatGPT was used as an assistance tool, not as a
replacement for my own work.
