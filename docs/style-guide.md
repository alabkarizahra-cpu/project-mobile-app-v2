# LocalLens Style Guide

## Colors
- Primary Color: #166B52
- Background Color: Warm Cream
- Success: Green
- Warning: Amber
- Error: Red

## Typography
- Clean sans-serif typography
- Bold headings
- Clear and compact body text

## UI Style
- Rounded cards
- Rounded buttons
- Consistent spacing and margins
- Clean and minimal interface
- Material 3 components

## Main Components
- Scaffold
- Navigation Bar
- Cards
- Buttons
- Text Fields
- Filter Chips
- Icons
