# LocalLens Style Guide

## Colors

- Primary Color: #0E7654 (LocalLens Green)
- Accent Color: #F6F0E3 (Soft Beige / Sand)
- Background Color: Warm Cream
- Success: Green
- Warning: Amber
- Error: Red

## Typography

- Clean sans-serif typography
- Bold headings
- Clear and compact body text

## UI Style

- Rounded cards
- Rounded buttons
- Consistent spacing and margins
- Clean and minimal interface
- Material 3 components

## Main Components

- Scaffold
- Navigation Bar
- Cards
- Buttons
- Text Fields
- Filter Chips
- Icons

- Home
